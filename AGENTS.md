# Keertana working agreement

Preserve the existing application, design direction, working features, and catalog content. Make the smallest safe change for the approved task.

## Owner preference: focused validation

For minor, reversible changes, avoid adding unnecessary tests or repeatedly running the full test suite. Use only the focused checks needed for the change; the owner will manually review minor visual and interaction changes. Run a production build when needed to generate or deploy pages. Bulk catalog edits, security changes, and other higher-risk work still need proportionate automated integrity checks. Explain any additional validation briefly before doing it.
